# NexUI - Network Intelligence Dashboard

A modern, AI-powered network management dashboard built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Real-time Network Monitoring** - Track active devices, network health, and performance metrics
- **AI-Powered Insights** - Predictive analytics and intelligent recommendations
- **Security Dashboard** - Monitor and block threats in real-time
- **Energy Analytics** - Track and optimize energy consumption
- **Interactive Voice Assistant (Vemo)** - Voice-controlled network management
- **Responsive Design** - Beautiful glass-morphism UI with smooth animations

## 📊 Dashboard Components

- **Metric Cards** - Active devices, network health, threats blocked, energy saved
- **Network Health Overview** - 24-hour performance charts with fullscreen view
- **Recent Alerts** - Real-time security and system notifications
- **Predictive Insights** - AI-powered recommendations
- **Quick Actions** - One-click network optimization, security scans, and reports

## 🛠️ Tech Stack

- **React 18** - Modern UI library
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Smooth animations
- **Recharts** - Data visualization
- **Lucide React** - Beautiful icons
- **Web Speech API** - Voice synthesis for Vemo assistant

## 📦 Installation

```bash
# Install dependencies
npm install
# or
pnpm install

# Start development server
npm run dev
# or
pnpm dev
```

## 🚀 Build for Production

```bash
npm run build
# or
pnpm build
```
